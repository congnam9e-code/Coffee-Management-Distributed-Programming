Đề tài: Quản Lý Quán Cafe (Client - Server)

Sinh viên thực hiện: [Điền tên bạn vào đây]

Giảng viên hướng dẫn: [Điền tên GV]

1. Đặt Vấn Đề

  • Mô hình kinh doanh quán cafe cần hệ thống quản lý tập trung, dữ liệu thời gian thực.
  • Nhu cầu xử lý dữ liệu đồng bộ giữa nhiều nhân viên ở nhiều máy tính (quầy) khác nhau.
  • Yêu cầu phân quyền người dùng rõ ràng (Quản lý vs Nhân viên).

2. Công Nghệ Sử Dụng

  • Kiến trúc phần mềm: Client - Server
  • Giao diện (Client): Java Swing
  • Giao tiếp mạng: Java Socket (TCP/IP), Java Object Serialization
  • Hệ quản trị CSDL: SQL Server
  • Thao tác dữ liệu (ORM): JPA / Hibernate

3. Kiến Trúc Hệ Thống

  • Phía Server: Lắng nghe kết nối tại Port 8888. Áp dụng cơ chế Đa luồng (Multi-threading) - mỗi Client kết nối sẽ được cấp 1 ClientHandler riêng biệt để xử lý.
  • Phía Client: Giao tiếp với Server bằng Request/Response thông qua ObjectInputStream và ObjectOutputStream. Áp dụng Singleton Pattern cho lớp Socket.
  • Database: Cấu hình hibernate.hbm2ddl.auto tự động mapping và khởi tạo Database Schema.

4. Demo Cấu Trúc Dữ Liệu

  • Bao gồm các thực thể (Entity) chính: Employee, Product, Category, CoffeeTable, Bill, BillDetail.
  • Mối quan hệ 1-n, n-n được cấu hình ánh xạ tự động qua các Annotation của JPA.
  • Dùng Data Access Object (DAO) Pattern để phân tách code truy vấn CSDL.

5. Chức Năng: Nhân Viên

  • Đăng nhập ca làm việc, cập nhật mật khẩu.
  • Theo dõi sơ đồ bàn theo thời gian thực (Bàn màu đỏ: Có khách, màu xanh: Trống).
  • Tiếp nhận yêu cầu: Thêm món ăn/thức uống vào bàn.
  • Thanh toán hóa đơn (Chốt Bill).

6. Chức Năng: Quản Lý

  • Quản lý Menu: Thêm, Sửa, Xóa các món ăn/thức uống, cập nhật giá.
  • Quản lý Nhân sự: Cấp phát tài khoản mới, phân quyền (MANAGER/STAFF), chỉnh sửa thông tin nhân viên.
  • Quản lý Hóa đơn: Kiểm soát và xem lại danh sách tất cả các hóa đơn đã được thanh toán trong hệ thống.

7. Tổng Kết

  • Ưu điểm đạt được: Mô hình mạng đa luồng chạy ổn định, chia layer rõ ràng, dùng JPA giúp code ngắn gọn và dễ bảo trì. Khắc phục được lỗi StackOverflow khi map quan hệ 2 chiều.
  • Hạn chế: Giao diện Swing còn cơ bản. Bảo mật mật khẩu lưu Database dưới dạng plain-text.
  • Hướng phát triển: Băm (hash) mật khẩu (VD: BCrypt), vẽ biểu đồ doanh thu tự động, thiết kế lại UI bằng FlatLaf.
